# 변환·검수 기록 · 2026-09-22

## 범위

최신 티저 사진 표지를 적용한 `index.html` 최종본 12장을 검수했습니다. `index-experimental.html`과 기존 experimental-cover 내보내기도 최종본과 12장 모두 동일합니다. PDF와 PPTX는 같은 HTML 내용·배치를 기준으로 생성했습니다.

## 글꼴과 배치

- 한국어 Noto Sans KR, 영어·숫자 Inter. 400·500·600·700의 총 8개 폰트 파일을 PPTX에 내장했습니다.
- 중간 굵기는 `Inter Medium`, `Inter SemiBold`, `Noto Sans KR Medium`, `Noto Sans KR SemiBold`라는 내부 패밀리 이름으로 매핑했습니다.
- 텍스트를 브라우저에서 측정한 줄·폰트 구간별로 배치했습니다. 음수 자간을 유지하며 자동 줄바꿈과 자동 축소를 사용하지 않습니다.
- 그림·배경·UI 도형은 HTML 렌더링의 비텍스트 층을 2560×1440 PNG로 고정했습니다. 텍스트는 이 위의 별도 편집 가능한 PowerPoint 개체입니다. 표의 문구도 편집 가능하지만 선·배경의 재배치는 HTML에서 하는 편이 적합합니다.
- 출처는 도형 수준 하이퍼링크로 연결해, PowerPoint 기본 링크 색상이 원래 글자색을 덮어쓰지 않도록 했습니다.

텍스트 내용은 PPTX XML과 PDF 추출 결과로 대조했고, 사진 표지와 주요 수정 페이지를 이미지로 확인했습니다. 사진 안에 원래 포함된 UI 글자는 래스터 이미지이므로 별도 텍스트 비교 대상이 아닙니다. 최신 티저의 배경 복원 영역 외 픽셀 동일성은 `assets/teaser-background-validation.json`에 기록했습니다. 이전 검증 JSON은 해당 수정 시점의 이력으로 남겼습니다.

최신 재출력에는 오른쪽 여백을 약 3% 넓힌 사진 표지와, 시작 위치를 유지하면서 초입만 더 어둡게 한 그라데이션을 반영했습니다. 첫 장 상단 영문 설명과 반복 영문 푸터는 삭제 상태를 유지했고, 페이지 번호는 모두 12장 기준으로 갱신했습니다. 티저 제목·하단 홍보 문구의 실제 폰트 로드도 별도로 확인했습니다.

## 검수 한계와 편집 안내

PPTX 검수에는 LibreOffice 24.2를 사용했고, 동일 폰트를 별도로 제공한 환경에서 렌더링했습니다. 이 버전의 LibreOffice는 PPTX 내장 폰트를 직접 활용하지 않으므로, 내장 여부는 패키지 구조로 별도 확인했습니다. **실제 Microsoft PowerPoint에서 직접 실행한 검수는 아닙니다.** 모든 모바일 뷰어에서 폰트 내장을 동일하게 지원한다고 보장할 수 없습니다.

단어를 긴 문장으로 바꾸면 텍스트 상자 위치·폭도 조정해야 할 수 있습니다. 여러 글꼴 구간은 한 줄 그룹으로 묶여 있습니다. 큰 문구·레이아웃 수정은 원본 HTML에서 진행하고 다시 내보내는 것이 가장 일관됩니다. 단순 열람·발표에는 HTML 기준 PDF가 가장 안정적입니다.
