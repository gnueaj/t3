# 3~5쪽 인물 뒤 그라데이션 후보 (2026-11-14, 덱에는 아직 넣지 않음)

3~5쪽 인물 뒤의 옅은 보라 그라데이션은 7차(11월 13일)에 넣은 그대로 덱에 있어요. '거의 티 안 나게'로 맞춘 값이라 지금은 잘 보이지 않아요. 세기만 달리한 세 가지를 나란히 놓았어요.

| 세기 | 뜻 |
| --- | --- |
| 0.26 | 지금 덱 |
| 0.42 | 조금 더 |
| 0.60 | 그보다 조금 더 |

`한눈에.jpg`의 위 줄은 5쪽 전체, 아래 줄은 인물 둘레를 크게 본 그림이에요. 세기는 몸 안쪽의 가장 진한 곳의 값이고, 윤곽 바로 밖은 그 절반쯤이에요(`tools/intro_assets.py`의 `AURA_MAX`). 띠나 테두리가 생기지 않게 윤곽을 크게 흐리는 방식은 그대로예요.

```
~/.cache/weave-tools/venv/bin/python -I tools/aura_try.py     # 한눈에.jpg를 다시 만듦
```
