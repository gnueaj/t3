## 장의 짜임

제목은 'S펜과 Bixby, 그리고 SmartThings로 잇는 미래의 Weave'예요. 34쪽의 제목처럼 이름(S펜, Bixby, SmartThings, Weave)만 보라색이에요.

1. 34쪽에서 넘기면(Morph) 연표가 왼쪽으로 옮겨 가요. 왼쪽 끝에는 두 줄이 Weave에서 만나는 곳만 남아요.
2. Weave에서 두 줄이 다시 갈라져 화살촉을 앞세워 오른쪽 끝까지 뻗어요. 위 줄은 기술, 아래 줄은 인프라예요. 두 줄은 연표의 두 줄보다 가운데 쪽이에요(가운데에서 40px씩).
3. (클릭) 위 줄에 34쪽의 마디와 같은 양식(아이콘, 해, 이름, 한 줄)으로 '2027- / 그려서 찾는 기억 / S펜 · 멀티모달 임베딩'이 떠요. S펜이 지나가며 메모가 그려지고, 메모에서 나온 보라 실이 삼성노트와 메시지의 기록 카드로, 다시 갤러리의 사진(결과)으로 이어져요.
4. (클릭) 아래 줄에 '2027- / 집에서 건네는 기억 / SmartThings · Bixby'가 떠요. 캘린더와 카카오톡 카드에서 나온 실이 SmartThings 아이콘에서 하나로 모여 한 줄로 냉장고의 화면에 닿고, 냉장고에서 나온 실 끝에 Bixby의 말(결과)이 떠요.
5. (클릭) 그 오른쪽에 스마트 TV 장면이 떠요. TV 바로 위의 말 조각에서 곧은 실이 Bixby 아이콘을 지나 TV의 가운데로 내려오고, TV 왼쪽의 갤러리와 삼성 뮤직 카드에서 나온 실은 TV의 왼쪽에 닿아요. TV에는 찾은 곡의 재생 화면(결과)이 떠요.

장면 전체를 감싸는 흰 상자는 없고, 메모, 기록 카드, 말 조각처럼 떠 있는 것에만 흰 바탕을 썼어요. 기록 카드는 덱 앞쪽(26쪽, 30쪽)의 카드를 작게 줄인 짜임이에요: 앱 아이콘, 굵은 이름, 작은 회색 줄('앱 이름 · 날짜'), 본문(카카오톡과 메시지는 회색 말풍선). 갤러리만 다르게, 회색 줄 없이 사진을 묘사한 글을 검정 이름으로만 적었어요. 결과(사진, Bixby의 말, TV)에는 보라 테를 둘렀어요. 캘린더와 카카오톡은 장 전체에서 한 번씩만 나와요(냉장고 장면).

## 대본 (49.2초)

> (넘기며) 저희가 그리는 미래의 Weave는 휴대폰 안에서만 머물지 않습니다.
>
> (클릭) 먼저 기술 측면에서는, 글자로만 찾던 방식을 멀티모달로 확장합니다. S펜으로 어렴풋이 기억나는 모습을 그리고 몇 글자를 적으면, 단서가 되는 메모와 대화를 통해, 이렇게 해당되는 사진을 찾아냅니다.
>
> (클릭) 인프라 측면에서는, 삼성전자가 이미 갖춘 가전과 TV 생태계로 뻗어 나갑니다. SmartThings로 기억이 집 안 기기와 이어지면, 홈파티를 앞두고 깜빡한 친구의 알레르기를 냉장고가 먼저 챙겨 주고요.
>
> (클릭) 스마트 TV에 ‘작년에 벚꽃 보러 갔을 때 여자친구랑 듣던 노래 틀어 줘’ 하고 말하면, Bixby가 찾아 틀어 줍니다. 휴대폰에서 가전과 TV까지, 삼성의 모든 기기가 기억을 나누는 생태계를 만들어 가겠습니다.

## 다시 만들기

```
~/.cache/weave-tools/venv/bin/python tools/next_try.py --only 미래의Weave            # 영상, 덱, 한눈에.jpg
~/.cache/weave-tools/venv/bin/python tools/next_try.py --deck --only 미래의Weave     # 덱과 정적 그림만(out/next_try/png_미래)
~/.cache/weave-tools/venv/bin/python tools/next_try.py --quick 미래의Weave           # 낭독 없이 빨리 찍어 봄
~/.cache/weave-tools/venv/bin/python tools/next_try.py --check --only 미래의Weave    # 영상에 넣은 낭독을 받아쓰기로 글과 견줌
```

장은 `next2_new.py`의 `s_next`이고, 통합 덱에는 `slides_new.py`의 `SLIDES_BACK`을 거쳐 들어가요. 1판은 `next_new.py`예요(`--only 미래A`처럼 부르면 다시 찍어요).
