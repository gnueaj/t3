## 장의 짜임

### (가) 2027년부터, 더 넓게 읽고 더 멀리 잇습니다 (26.6초, 클릭 둘)

1. 35쪽에서 넘기면(Morph) 연표가 왼쪽으로 옮겨 가요. 왼쪽에는 2026년 마디와 Weave만 남아요.
2. Weave에서 두 줄이 다시 갈라져 오른쪽 끝까지 뻗고, 줄을 따라 작은 빛이 달려 나가요. 위 줄은 기술, 아래 줄은 갤럭시(인프라)예요.
3. (클릭) 위 줄에 35쪽의 마디와 같은 양식(아이콘, 해, 이름, 한 줄)으로 '2027- / 그려서 찾는 기억 / S펜 · 멀티모달 임베딩'이 뜨고, 그 오른쪽에 장면이 떠 있는 조각으로 놓여요.
   S펜이 지나가며 메모가 그려지고 → Weave → 갤러리의 사진이 뜨고 → 그 사진에 이어진 캘린더('10월 4일 강릉 여행')와 카카오톡('엄마: 바다 또 가자') 기록이 붙어요.
4. (클릭) 아래 줄에 '2027- / 집에서 건네는 기억 / SmartThings · Bixby'가 뜨고, 휴대폰 → SmartThings → 냉장고 → Bixby의 말('지은님은 새우를 못 드세요 / 오늘 저녁 메뉴에서 뺄까요?')과 그 말이 나온 기록('지은: 나 갑각류 알레르기 있어')이 차례로 떠요.

전체를 감싸는 흰 상자는 없고, 메모, 사진, 기록 조각, 말 조각처럼 떠 있는 것에만 흰 바탕을 썼어요.

### (나) 기록에서 기기까지, 모든 것을 잇는 Weave (5.8초, 클릭 없음)

한 번 더 넘기면 (가)의 모든 것이 왼쪽으로 물러나고, 두 줄이 서로 엮이며 오른쪽으로 뻗어요. 마루마다 위에는 기록(카카오톡, 갤러리, 삼성노트, 캘린더, 이메일, 지도, 월렛), 아래에는 기기(휴대폰, 워치, 노트북, TV, 냉장고, 세탁기, 차)가 꿰이고, 두 가닥이 엇갈리는 자리마다 작은 Weave가 있어요. 아래에는 2027, 2028, 2029, 2030의 눈금이 이어져요. 눈금은 마디 바로 아래가 아니라 엇갈리는 자리에 두어서, 해마다의 계획처럼 읽히지 않게 했어요.

(나)를 빼고 (가)만 쓸 수도 있어요. 그때는 맺는 문장을 (가)의 끝에 말하면 돼요.

## 다시 만들기

```
~/.cache/weave-tools/venv/bin/python tools/next_try.py --only 미래2     # 영상, 덱, 한눈에.jpg
~/.cache/weave-tools/venv/bin/python tools/next_try.py --deck          # 덱과 정적 그림만(out/next_try/png_미래)
~/.cache/weave-tools/venv/bin/python tools/next_try.py --quick 미래2    # 낭독 없이 빨리 찍어 봄
~/.cache/weave-tools/venv/bin/python tools/next_try.py --check --only 미래2     # 영상에 넣은 낭독을 받아쓰기로 글과 견줌
```

장은 `next2_new.py`의 `s_next2a`, `s_next2b`예요. 1판은 `next_new.py`(`--only 미래A`처럼 부르면 다시 찍어요).
